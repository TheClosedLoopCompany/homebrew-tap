# The Closed Loop Company — Homebrew tap

```sh
brew install --cask theclosedloopcompany/tap/listenr
```

[Listenr](https://listenr.live) — bot-free meeting notes for macOS with real
speaker attribution. Signed + notarized; includes the `listenr` CLI and MCP
server on your PATH.

Casks in this tap are generated by the release pipeline in the main Listenr
repo (`Scripts/release.sh`) — don't edit them by hand.
